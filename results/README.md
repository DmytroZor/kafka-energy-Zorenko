# Матеріали для звітності

- `REPORT_01.md`: Kafka, Python Producer/Consumer, monitoring, benchmark, відповіді на контрольні питання.
- `REPORT_02.md`: Cassandra keyspace, таблиці, seed, індекси, CRUD, TTL, nodetool.
- `REPORT_03.md`: Cassandra Simple Wide Row проти Hourly Bucketing, фізична статистика та benchmark.
- `REPORT_04.md`: наскрізний Kafka → Bytewax → Cassandra stream processing, аномалії, вікна, latency і графіки.

Після виконання на власному комп'ютері в цю папку автоматично додаються: `p3_generation_metadata.json`, `p3_bad_tablestats.txt`, `p3_good_tablestats.txt`, `p3_partition_comparison.csv`, `p3_benchmark.csv`, `p4_probe.csv`, `energy_metrics.png` (залежно від викликаних команд). Замість `[вставити]` у звітах слід включити **реальні** скриншоти та виміряні показники.

Для кожної роботи надано **два формати звіту:** `.md` та готовий для редагування `.docx` з титульною сторінкою, змістовою частиною і таблицями. В обох форматах місця для реальних результатів ще треба заповнити після експерименту.

Шаблони навмисно не видають гіпотетичні результати за виконані. Якщо курс вимагає формат DOCX, перенесіть підготовлені розділи у Word та вставте перевірені знімки екрана.
